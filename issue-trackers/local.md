# Local Issue Operations

Store issues as Markdown files under `/.hyperspec/issues/<name>.md` using a concise kebab-case `<name>`.

## List / Search Issues

List `*.md` files in `/.hyperspec/issues/` or search their contents when filtering by query.

## View an Issue

Read `/.hyperspec/issues/<name>.md`.

## Create an Issue

Ensure `/.hyperspec/issues/` exists, then write `/.hyperspec/issues/<name>.md` starting with `# <title>` followed by the issue body.

## Update an Issue

Edit `/.hyperspec/issues/<name>.md`.

## Complete an Issue

Remove `/.hyperspec/issues/<name>.md` from `/.hyperspec/issues/`.
